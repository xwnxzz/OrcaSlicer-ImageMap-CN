## 完整包用法

1. 右键下载到的 zip → **属性 → 勾选"解除锁定"** → 解压到任意目录（路径尽量简单，别带特殊符号）。
2. 双击 **`启动 OrcaSlicer-ImageMap.cmd`**。
   首次运行会自动清除程序文件的 Internet 标记，并在**桌面创建快捷方式**，然后启动应用。
3. **不要用"以管理员身份运行"**（会导致下次普通启动异常）。

## 补丁用法（已有上游便携版）

```powershell
# 把 zh-tsv.tsv 和 apply-zh-mo.py 放到同一个目录，然后：
python apply-zh-mo.py
```

脚本行为：先把现有 `.mo` 备份为 `OrcaSlicer.mo.原始备份`，再以**字节级追加**方式把对照表中
缺失的条目写进去——**只新增，不覆盖任何既有翻译**。重复执行安全。

## 汉化了什么

- `.mo` 条目数 **5219 → 5425**，新增 **206 条**中文，未覆盖或删除任何既有翻译。
- 覆盖范围：管理颜色数据对话框、纹理映射区菜单与按钮、调制模式及各选项、
  2D / 线性 / 径向渐变、顶点色与 RGBA 数据操作、图像纹理导入 / 载入 / 投影、
  擦拭塔图像、以及 ImageMap 新增设置项的标签与提示文字。
- **未覆盖**：fork 新增的超长句（源字符串 >90 字符，从二进制只能取到截断片段，无法安全匹配）、
  fork 内部报错/日志字符串（源码未使用翻译宏，改 `.mo` 无效）、以及与本 fork 无关的
  约 80 条上游未翻译项。欢迎按下面方式继续补。

## 继续补翻译 / 升级后重做

往 `zh-tsv.tsv` 追加 `英文<TAB>中文` 行，再跑一次 `apply-zh-mo.py` 即可。
升级应用（`resources/` 被覆盖）后同样跑一次即可恢复汉化。

## 用法与省料要点（摘要）

- **这个 fork 的核心**：每层只用一种耗材，靠**调制外壁 overhang / 线宽**形成明暗，
  逐层轮换颜色把图"织"在模型侧面。
- 第一次跑：导入 OBJ / glTF / GLB（带贴图或顶点色）或使用「图像投影」→
  设好**多材料设置里的外壁线宽最小/最大**（0.4 mm 喷嘴 0.32–0.95）与**调制模式** →
  选 CMYK / CMYW / RGBW 或 Generic Solver → 切片后在预览逐层检查。
- **省料（多色耗材大头是换料冲刷）**：层高 0.16–0.2 mm 可让换料次数减半；
  同材料/相近颜色可把冲刷倍率降到 0.3–0.4、相近色的冲刷量改到 20–60 mm³；
  打开「冲刷到填充/支撑」；一盘多件分摊换料；减少颜色数；收窄调制线宽范围。
- 完整说明见完整包内的 `使用说明.md`。

## 已知限制

- **云功能不可用**：登录（上游服务端接口已下架，404）、云打印、云预设同步、MakerWorld、
  远程监控都会失败，有时弹「证书已过期」。本地切片 / ImageMap / LAN / SD 卡打印正常。
- 打开由更新版 BambuStudio 保存的 3MF 时会提示"版本更新、部分设置无法识别"，点确认即可使用。
