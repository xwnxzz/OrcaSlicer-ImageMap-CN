# OrcaSlicer-ImageMap 汉化（中文补丁）

本目录保存把应用界面**补成中文**所需的一切，方便升级版本后重做。

## 已经做了什么

应用自带的 `resources/i18n/zh_CN/OrcaSlicer.mo` 里**只有上游的翻译**，这个 fork 新增的
ImageMap 界面文字（菜单、按钮、对话框、选项、设置项标签与提示）没有中文，所以显示英文。

我做的事：
1. 从应用二进制 + 源码里找出「存在于程序、但中文翻译文件里缺失」的 ImageMap 相关字符串；
2. 逐条翻译（术语与 OrcaSlicer 现有中文保持一致：外墙 / 耗材 / 悬垂 / 擦拭塔 / 纹理 /
   顶点色 / 渐变 / 调制 / 图集 …）；
3. 以**字节级追加**的方式合并进 `OrcaSlicer.mo`（不动任何既有翻译、保留元数据与复数条目）。

结果：`5219 → 5425` 条，**新增 206 条中文**，已通过 Python `gettext` 加载校验
（元数据 `zh_CN` / `UTF-8` / 复数规则完好，既有翻译未受影响）。

## 生效方式

**重启 OrcaSlicer-ImageMap**（翻译文件在启动时加载）。

## 覆盖范围与已知未覆盖

- ✅ 已覆盖：中英对照表 `zh-tsv.tsv` 里的 206 条，主要是
  「管理颜色数据」对话框、纹理映射区相关菜单与按钮、调制模式与各选项、
  2D 渐变/线性/径向渐变、顶点色与 RGBA 数据操作、图像纹理导入/载入/投影、
  擦拭塔图像、设置项标签与提示文字（`PrintConfig.cpp` 里的 `L(...)`）。
- ⚠️ 未覆盖：
  - 部分**长句**（超过 90 字符，从二进制里只能拿到截断片段，无法安全匹配）；
  - fork 内部**错误/日志字符串**（源码里没走翻译宏，改 `.mo` 也不会生效）；
  - 与本 fork 无关的**其它上游未翻译项**（约 80 条设置标签/提示）。

需要继续补，把新条目按 `英文<TAB>中文` 追加到 `zh-tsv.tsv`，再跑一次脚本即可。

## 升级版本后重做

```powershell
# 应用关闭状态下执行
python "C:\Users\xzz\Desktop\dc works\orcaslicer-imagemap\汉化\apply-zh-mo.py"
```

脚本行为：
- 只**新增** `zh-tsv.tsv` 里、目标 `.mo` 里还没有的条目（已存在的一律不覆盖）；
- 首次运行会把当前 `.mo` 备份到 `OrcaSlicer.mo.原始备份`。

## 回滚

把 `OrcaSlicer.mo.原始备份` 复制回
`..\OrcaSlicer\resources\i18n\zh_CN\OrcaSlicer.mo` 并重启应用即可恢复成原样。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `zh-tsv.tsv` | 中英对照表（`英文<TAB>中文`，一行一条，可继续追加） |
| `apply-zh-mo.py` | 合并脚本（字节级追加 + 正确 MO 写回 + 备份） |
| `OrcaSlicer.mo.原始备份` | 原始未修改的翻译文件（回滚用） |
